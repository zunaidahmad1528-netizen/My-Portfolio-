# Zunaid — Data Analyst Portfolio

A personal portfolio website showcasing my journey as an aspiring Data Analyst, built as a single-page, animated dark-themed site.

🔗 **Live Demo:** _(add your GitHub Pages link here once deployed)_

## About

I'm a Computer Science Engineering student (2024–2028) working toward a career as a Data Analyst, with data engineering as the next step and Dubai as a long-term target market. This portfolio reflects that goal — highlighting end-to-end, working projects rather than isolated scripts.

## Features

- Sticky nav with smooth scroll navigation
- Animated hero section with a mock "data terminal" visual and live scroll-progress bar
- Scroll-triggered reveal animations for sections and staggered elements
- Animated stat counters (projects shipped, graduation year, etc.)
- Fully responsive, single-file layout (HTML + inline CSS + vanilla JS)

## Tech Stack

- **HTML5** — semantic single-page structure
- **CSS3** — custom properties (CSS variables), Grid/Flexbox, keyframe animations
- **Vanilla JavaScript** — `IntersectionObserver` for scroll reveals & counters, scroll-progress bar
- **Fonts:** Space Grotesk, Inter, JetBrains Mono (Google Fonts)

## Featured Projects

1. **DataChat AI** — MVC-structured Flask app with auth, data cleaning, multi-file comparison, export
2. **AI-Powered Resume Analyzer** — Flask + Claude API for resume feedback
3. **Air Quality India — EDA** — End-to-end exploratory data analysis (Pandas, Matplotlib)
4. **Retail Sales Analysis** — Sales trend analysis using Python, Pandas, NumPy

Deployed via **GitHub Pages**:

2. Go to Settings → Pages → select `main` branch as source
3. Site goes live at `https://zunaidahmad1528-netizen.github.io/<repo-name>`
